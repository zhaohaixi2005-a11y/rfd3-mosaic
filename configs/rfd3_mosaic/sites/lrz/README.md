# LRZ deployment profiles

These profiles are private-site deployment compatibility files for existing
RFD3-Mosaic experiments. They are not public hardware requirements and are
not included in the installable RFD3-Mosaic wheel or source distribution.

The short legacy profile identifiers `v100`, `p100`, `a100_80g` and `h100`
continue to resolve from a source checkout so frozen experiment YAML files do
not need to change.
