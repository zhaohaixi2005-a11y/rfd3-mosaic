# Structure fixtures

These small coordinate files support maintained examples and regression tests.
They are input fixtures, not generated benchmark results or claims of
experimental success.

Before a public source release, each fixture must have a recorded source,
derivation and redistribution permission. The repository-level
[`PUBLIC_RELEASE_CHECKLIST.md`](../../../PUBLIC_RELEASE_CHECKLIST.md) is the
authoritative release gate. A fixture may remain in a private laboratory branch
while that review is pending, but it must not be assumed public merely because
it is tracked.
