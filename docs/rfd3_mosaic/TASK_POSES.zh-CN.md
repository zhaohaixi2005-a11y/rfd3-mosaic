# 任务、初始 pose 与刚体移动

## 一个任务只使用一个起始 pose

一份 `design.yaml` 是一个任务。`sampling.designs: 1000` 表示从同一套
seed 起始坐标生成 1000 份结构，扩散种子依次为 `sampling.seed + i`。
初始姿态分布只实现一次，不随 design 编号重采样。模型每个任务加载一次。

两个控制互相独立：

| 设置 | 输入 pose | 生成中的 seed |
|---|---|---|
| `preferences.component_motion: locked` | 全部 design 共用 | 保持选定摆放 |
| `guided` / `free` | 全部 design 共用 | 各 design 可按声明边界独立移动刚体 |

所有模式保持同一刚体内部几何；对称副本按群作用更新。共用初始 pose 不意味着
可移动模式的最终 pose 相同，也不保证不同任务的最终 pose 不会收敛。
显式组件的运动约束仍然适用；本命令不重写它们。

普通 `run` 对声明的随机 pose 保留一个通过运行前检查的候选。要在生成前比较
多个候选、筛选不同任务的 pose，使用下面的 `prepare-poses`。

## 先准备不同 pose，再分别运行任务

给模板声明允许的摆放范围，例中的半径、轴向范围只是示例，不是所有 seed 的推荐值：

```yaml
sampling:
  designs: 1000
  seed: 42
  initial_pose:
    radius: {minimum: 20, maximum: 32}
    axial_offset: {minimum: -4, maximum: 4}
    orientation: {method: uniform_so3}
    seed: 100
preferences:
  component_motion: locked
```

```bash
rfd3-mosaic prepare-poses design.yaml \
  --output-dir tasks \
  --count 4 \
  --candidates 32 \
  --seed 100 \
  --minimum-separation 1.0
```

该 CPU 命令在声明范围中尝试 32 个候选，最多写出 4 份不同起始 pose 的任务 YAML。
运行输出中列出的每条 `rfd3-mosaic run ...` 命令即可。每个任务仍生成 1000 份结构，
不会把这 1000 份分配到 4 个 pose。`--profile` 可在各任务运行时指定。

全部任务继承模板的 `output.root`，不会在每个任务目录下另建结果根目录。
`init` 和复制示例的默认结果根目录是 `runs/rfd3-mosaic`；用户显式指定的根目录
始终优先。运行结果沿用 `ROOT/日期/任务名/运行编号`，不同批次靠任务名和编号区分。
`--output-dir tasks` 只存放准备好的任务配置、输入副本和筛选报告。

显式多刚体输入使用按 coupling group 命名的 `sampling.initial_poses`，沿用同一
筛选流程。Cn/Dn 的连接图必须先正确声明；该命令不发明连接关系，也不把 Dn
降为单层圆环。未声明变量范围的固定输入会被拒绝，不会偷偷移动。

输出包含输入结构副本、任务 YAML 和 `pose_tasks.json`。每个 pose 都转换成确定的
半径、轴向偏移和旋转，并重新编译验证全部输入原子最大逐坐标误差不超过 `1e-5 Å`。
移动模式保持不变。相同模板、参数和软件版本可重现结果；重跑同一个任务不会
自动换 pose，改名字也不会改变随机状态。不同任务的差异由本次任务集合的筛选
保障，不是跨任意目录、历史运行的全局去重。

## 筛选标准

硬检查来自编译器：固定块碰撞、必需界面、连接最大长度是否足够及必需输出目标。
它们不能被软评分改善抵消。

通过后按公开几何评分逐项排序：不同连接内部弦的拥挤比例、弦与固定块障碍、
长度不足项、用户目标惩罚、端点朝向、走廊净空和端点距离等；完整元组保存在报告。
长度不足项在可行候选中为零。轴线净空仍报告，但不再把“离轴越远越好”作为通用排名。

拥挤比例：取每条端点弦的 10%–90% 内部段，对没有共同端点的连接两两测距；
小于 `1 Å` 的对数除以被比较对数。它是粗略走线风险，不是主链实际碰撞概率。
固定块走廊阈值 `2 Å`、端点折返提示 `120°` 以及 Cn 的 wedge/tangent 描述同样
属于启发式。真实柔性链可能绕行，因此这些描述不再单独导致运行前硬拒绝。
几何可行不保证折叠、packing 或最终不穿插，结果仍须审计。

## 怎样定义不同 pose

收集完整对称装配中、属于不同刚体实例的 Cα 对距离，排序成向量 `s`：

```text
D(A,B) = sqrt(mean((sort(s_A) - sort(s_B))**2))
```

按质量排序遍历候选，仅当它与所有已选代表的 `D >= minimum_separation` 时保留。
默认 `1 Å` 是描述符去重分辨率，不是生物学阈值，可以显式调整。
整体旋转、平移和副本重编号不会改变该距离谱，因此不会制造虚假多样性。

这是保守描述符，**不是对齐 RMSD，也不是形状的唯一编码**：不同结构乃至镜像可能
具有相同距离谱，导致少保留候选。当前最多比较 4096 个 seed Cα 原子，超出会明确报错。
全部输出代表满足声明的描述符间距；若只找到 2 个，就报告 2/4，不降低阈值补足数量。
未选候选的指标、排除理由也写入报告。这只证明输入 pose 的差异，不证明生成骨架
多样性、不同折叠数量或可移动模式的最终 pose 差异。

## 旧配置迁移

删除 `replicates_per_pose`。它过去可以把一个任务拆成多个 pose，现在任务内始终
共享一个输入。显式旧值不等于 `designs` 会报迁移错误，防止静默改变旧实验含义。
需继续比较多个 pose 时，先用 `prepare-poses` 生成独立任务。
